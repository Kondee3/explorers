# Explorers
An explorer app made in Tauri framework.
- Frontend: React(tsx)
- Backend: Rust

## Features 
- Search input
- Path input
- Go to upper directory
- Sort by name/type/size

## Platforms
- Windows ✅
- Linux ✅
- Mobile ⚠️
## Development 
 ```
 bun run tauri dev
 ```
## Build
```
bun run tauri build
```
